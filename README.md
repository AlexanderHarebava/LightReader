Light Reader

The app is a modern mobile e-book reader powered by the Readium Kotlin Toolkit for the Android platform. It combines core reading features for various book formats, a built-in library, and advanced AI-driven capabilities.



Key Features and Functionality

1\. Reading and Supported Formats

Supported Formats: EPUB, PDF, FB2, TXT, DOCX.



Built-in Converters: Automatic conversion of FB2, TXT, and DOCX files to EPUB format for a seamless reading experience.



Display Customization: Adjustable fonts, text size, and color themes (light/dark), along with a quick settings menu to adapt to user preferences.



Navigation and Bookmarks: Reading progress tracking, bookmark creation, text highlighting, and table of contents (Outline) navigation.



Text-to-Speech (TTS): Built-in text audio playback with controls for speech rate and voice selection.



In-Book Search: Full-text search within open books.



2\. Bookshelf and Library Management

User Interface: A modern library view built with Jetpack Compose.



Filtering and Tags: Tagging books as "Favorites," "Want to Read," or "Read".



Sorting and Metadata: Displays file size, date added, format type, and reading progress percentage.



Cover Generation: Automatic generation of text-based or graphical covers when original art is missing.



3\. AI Assistant Integration

The app features an AI assistant capable of analyzing text, answering questions, and maintaining contextual conversations about uploaded books.



Supported AI Providers:



Google Gemini (direct integration with full-text analysis).



OpenAI (models such as gpt-4o-mini and embedding workflows).



DeepSeek (deepseek-chat and both local or cloud setups).



OpenRouter (access to a wide range of third-party models).



RAG (Retrieval-Augmented Generation):



Text chunking with configurable overlap.



Vector embedding generation and caching.



Relevant passage retrieval via cosine similarity for accurate AI responses grounded in the book's content.



Chat Management:



Chat history persistence saved in JSON format.



Session management: create, rename, or delete threads.



Chat export to .txt files with quick sharing options.



Ability to attach specific library books to active chat sessions.
